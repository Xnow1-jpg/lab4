# Отчёт по лабораторной работе №4: «Написание Unit-тестов»

---

## 1. Цели и задачи тестирования
* **Цель**: автоматизированная проверка корректности вычисления геометрических характеристик (площади и периметра) для набора геометрических фигур при помощи модульного тестирования.
* **Задачи**:
  * Разработать тестовые сценарии с использованием стандартного фреймворка `unittest` для модулей `circle.py`, `rectangle.py`, `square.py` и `triangle.py`.
  * Исключить дублирование «магических чисел» в тестах за счёт выноса тестовых данных в именованные константы (`UPPER_SNAKE_CASE`).
  * Реализовать для каждого геометрического модуля 4 обязательных класса сценариев:
    1. Позитивные тесты на корректных положительных значениях.
    2. Негативные тесты на отрицательных значениях (проверка недопустимости отрицательных сторон и радиусов с ожиданием `ValueError`).
    3. Негативные тесты на проверку типов (передача строковых параметров с ожиданием `TypeError`).
    4. Граничные значения (проверка поведения функций при нулевых размерах).
  * Провести тестирование без изменения исходного кода самих библиотек, выявить дефекты и оформить отчёт.

---

## 2. Описание тестируемого продукта
Тестируемый продукт представляет собой библиотеку математических модулей на языке Python для вычисления базовых параметров двумерных фигур:
* **Круг (`circle.py`)**: функции `area(r)` (вычисление площади) и `perimeter(r)` (вычисление длины окружности).
* **Прямоугольник (`rectangle.py`)**: функции `area(a, b)` (площадь по двум сторонам) и `perimeter(a, b)` (периметр).
* **Квадрат (`square.py`)**: функции `area(a)` (площадь по стороне) и `perimeter(a)` (периметр).
* **Треугольник (`triangle.py`)**: функции `area(a, h)` (площадь по основанию и высоте) и `perimeter(a, b, c)` (периметр по трём сторонам).

Требования предметной области: длины сторон, высоты и радиусы фигур должны выражаться неотрицательными числовыми величинами ($r \ge 0$, $a \ge 0$, $b \ge 0$, $c \ge 0$, $h \ge 0$).

---

## 3. Область тестирования
В область тестирования входит проверка корректности возвращаемых значений и обработки ошибок публичных функций:
* `circle.py`: `area(r)`, `perimeter(r)`.
* `rectangle.py`: `area(a, b)`, `perimeter(a, b)`.
* `square.py`: `area(a)`, `perimeter(a)`.
* `triangle.py`: `area(a, h)`, `perimeter(a, b, c)`.

Вне области тестирования: нагрузочное тестирование, проверка производительности при экстремально больших числах, интеграция с внешними системами.

---

## 4. Стратегия тестирования
* **Уровень тестирования**: модульное (unit-тестирование).
* **Подход**: тестирование методом «чёрного ящика» (Black Box Testing) — тестовые случаи строятся исключительно на математических формулах и ожидаемом поведении функций без привязки к их внутренней реализации.
* **Методы тест-дизайна**:
  * Разбиение на классы эквивалентности (допустимые положительные числа, недопустимые отрицательные числа, некорректные типы данных).
  * Анализ граничных значений (нулевые размеры).
* **Организация данных**: входные параметры зафиксированы в константах (`VALID_*`, `NEGATIVE_*`, `STRING_*`, `ZERO_*`).
* **Инструмент запуска**: консольный модуль `unittest` (`python -m unittest discover -s tests`).

---

## 5. Критерии приёмки
1. Для каждого из 4 модулей реализовано по 8 unit-тестов, сгруппированных по 4 обязательным типам проверок (всего 32 теста).
2. Исходный код геометрических фигур остался неизменным (`circle.py`, `rectangle.py`, `square.py`, `triangle.py`).
3. Файлы тестов структурированы в директории `tests/` и зафиксированы коммитом в репозитории Git.
4. Все сбои тестов задокументированы с указанием локализации и причин ошибок (неверная математическая формула или отсутствие валидации входных данных).

---

## 6. Ожидаемые результаты
* Успешное выполнение тестов на нормальных положительных данных, нулевых границах и строковых типах (выброс `TypeError` на уровне арифметических операций Python).
* Фиксация провала (`FAIL`) на тестах с отрицательными входными величинами, если функции фигур не содержат явного выброса исключения `ValueError`.
* Фиксация провала (`FAIL`) на модулях с некорректными математическими формулами.
